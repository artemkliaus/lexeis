# Λέξεις: приложение для запоминания греческих слов

Личное приложение-карточки для изучения греческой лексики (перевод на русский). Работает как Telegram Mini App внутри бота и как обычная веб-страница. Хостинг: GitHub Pages, ветка `main`, корень репозитория. Всё общение и интерфейс на русском.

## Файлы

- `index.html` — всё приложение в одном файле: HTML, CSS и JS без сборки и зависимостей. Держать его самодостаточным.
- `bot.mjs` — необязательный бот на Node 18+ без зависимостей: ставит кнопку меню «Учить», обрабатывает `/start` и `/stop`, раз в день шлёт напоминание. Запуск: `BOT_TOKEN=... WEBAPP_URL=https://<логин>.github.io/lexeis/ REMIND_HOUR=19 TZ=Asia/Nicosia node bot.mjs`. Хранит подписчиков в `lexeis-bot.json`.
- Токен бота **никогда** не попадает в `index.html` или в репозиторий: страница публичная. Только переменная окружения для `bot.mjs`.

## Деплой

Коммит и пуш в `main`, GitHub Pages пересобирает сам за 1–2 минуты. Telegram кэширует webview: если изменения не видны, закрыть Mini App полностью и открыть заново (или добавить `?v=N` к URL кнопки меню в @BotFather).

## Устройство index.html

**Состояние** (`state`): `{ words[], settings, stats, updatedAt }`.
- Слово: `{ id, gr, ru, note, deck, created, srs }`, где `srs = { state: 'new'|'learning'|'relearning'|'review', due, interval (дни), ease, reps, lapses, step }`.
- `settings`: `newPerDay` (20), `autoSpeak`, `theme` ('auto'|'light'|'dark'), `mode` ('gr'|'ru'|'mix'), `deck` ('__all' или имя колоды), `strictAccents` (false).
- `stats`: `days` (дата → число повторений, для серии дней), `newDate`/`newCount` (лимит новых в день).
- `save()` ставит `updatedAt = Date.now()`, пишет в localStorage (ключ `lexeis:v1`) и планирует отправку в облако.

**Синхронизация через Telegram CloudStorage** (только внутри Telegram, Bot API 6.9+): весь `state` как JSON режется на куски по 2000 символов в ключи `lx0..lxN`, плюс `lx_meta = {n, t}`. Лимит значения 4096, 2000 выбрано с запасом на случай подсчёта в байтах UTF-8. При старте `pullCloud()`: побеждает сторона с большим `updatedAt` (last-writer-wins для всего состояния). Отправка с дебаунсом 1.2 с, меняются только изменившиеся куски, лишние удаляются. При `visibilitychange → hidden` отправка немедленно. Вне Telegram — только localStorage, перенос через резервную копию JSON в настройках.

**Интервальные повторения** (`schedule(srs, grade, now)`, оценки 0–3): изучение шагами 1 мин → 10 мин → 1 день («легко» сразу 4 дня); повторение: hard ×1.2, good ×ease, easy ×ease×1.3; провал ease −0.2 (мин. 1.3), интервал ×0.5 и переобучение. Сессия: сначала карточки к повторению, новые вставляются через каждые 3. Карточки в изучении возвращаются в очередь сессии через 3–5 позиций. «Тренировка без расписания» — до 30 случайных слов, расписание не меняется.

**Режимы.** На каждой карточке ответ нужно ввести:
- `gr` — показано греческое слово (озвучивается), пишешь перевод по-русски;
- `ru` — показан перевод, пишешь по-гречески;
- `mix` — направление случайно для каждой карточки.
Ввод не на том языке не засчитывается ошибкой, а показывает подсказку (toast).

**Проверка греческого ответа** (`checkAnswer`):
- сравнение без ударений и регистра, ς = σ, артикль необязателен (`ARTICLES`), варианты через `,` `;` `/`;
- можно латиницей (greeklish): `grToLat` + `latCanon` приводят обе стороны к фонетическому скелету (ου→u, χ/ch/x→h, ξ/x/3→ks, θ/8→th, η/ι/υ/y→i, ω/w→o, ai→e, ei/oi→i, двойные буквы схлопываются);
- опечатки по Левенштейну: 1 при длине ≥4, 2 при ≥10 → вердикт «почти»;
- при верных буквах, но другом ударении `accent: true`. Если `settings.strictAccents` выкл. — «Верно. Проверь ударение». Если вкл. — нужен ввод греческими буквами, а неверное или пропущенное ударение даёт вердикт `accent` (ошибка, есть кнопка «Засчитать»).

**Проверка русского ответа** (`checkRu`): без регистра и знаков, ё = е, любой вариант через `,` `;` `/` ` - `, текст в скобках необязателен, те же допуски на опечатки. Синонимы вне списка засчитываются кнопкой «Мой ответ тоже верный».

**Импорт** (`parseList`): одна строка — одно слово; разделители: табуляция, ` — `, ` – `, ` - `, ` = `, ` | `, `;`, `|`, `=`, затем `-` без пробелов, затем первая запятая. Греческая часть определяется автоматически, третья часть — заметка. Строки с `#` пропускаются, дубли (по нормализованному греческому) не добавляются.

**Telegram-интеграция**: `ready()`, `expand()`, `disableVerticalSwipes()` (7.7+), системная кнопка «Назад» (выход из сессии или на главную), подтверждение закрытия во время сессии, цвета шапки и фона под тему приложения, тема `auto` следует `colorScheme` Telegram, вибрация при оценке и проверке, приветствие по `first_name`. Все вызовы обёрнуты в проверки версии и try/catch, вне Telegram страница работает как обычная.

**Озвучка**: Web Speech API, голос `el-GR`. В Telegram на Android webview часто не поддерживает синтез речи.

## Дизайн и тексты

- Шрифты: GFS Didot для греческого (крупное слово на карточке — главный визуальный элемент), Commissioner для интерфейса; оба с Google Fonts с фолбэками.
- Палитра (светлая): фон `#EDF1EF`, поверхность `#FFFFFF`, текст `#14233A`, море `#1D5899`, олива `#5A6A27`, янтарь `#966600`, ошибка `#B2423A`. Тёмная тема — те же токены в `@media (prefers-color-scheme: dark)` и `:root[data-theme="dark"]`.
- Мобильная навигация снизу (≤640px) с отступами `env(safe-area-inset-*)`, скрывается во время сессии.
- Тексты: русский, обычный регистр, без капса в подписях, кнопки называют действие. Ошибки и пустые состояния объясняют, что делать дальше.
- Не использовать `confirm()`/`alert()` (в webview могут быть заблокированы): опасные действия подтверждаются вторым нажатием (`data-confirm`).

## Проверка изменений

Синтаксис: вытащить последний `<script>` и прогнать `node --check`. Поведение: Playwright с подменой `telegram-web-app.js` на мок `window.Telegram.WebApp` (включая `CloudStorage` с хранилищем в объекте) — так проверяется и синхронизация «второго устройства» через очищенный localStorage.

## Возможные следующие шаги (не решено)

- Цифры в напоминаниях бота («у тебя 14 повторений») — потребует хранить прогресс на сервере бота с проверкой `initData`.
- Вернуть режим «показать ответ и оценить себя» отдельным переключателем.
